Acquisition simple
--------------------

Dans ce tutoriel, vous verrez comment

#. Contrôler plusieurs broches numériques d'un Arduino en parallèle;
#. Comment lire les valeurs de plusieurs broches analogiques ou
   numériques en parallèle;
#. Comment communiquer avec l'Arduino avec Python (en parallèle);
#. Comment sauvegarder les données acquises du Arduino avec Python.
