Interface graphique de contrôle et affichage
------------------------------------------------

.. warning::

   En date du 28 août cette section n'est pas complète.

.. warning::

   Assurez-vous d'avoir un prototype fonctionnel et caractérisé avant de commencer ce tutoriel.

.. admonition:: Pré-requis

   Ce tutoriel assume que vous avez complété les tutoriels
   :doc:`acq`, :doc:`calcul` et :doc:`plot`.

Dans ce tutoriel, vous verrez:

#. Comment utiliser la ligne série pour exécuter des commandes
   arbitraire avec l'Arduino et Python;
#. Comment construire une interface graphique avec :py:mod:`tkinter`;
#. Comment lier un bouton à une commande;
#. Comment afficher une valeur dans un champ de texte;
#. Comment intégrer un graphique dans votre interface graphique.
