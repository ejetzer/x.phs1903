Calcul numérique en direct
----------------------------

.. admonition:: Pré-requis

  Ce tutoriel assume que vous avez complété et compris :doc:`acq`.

Dans ce tutoriel, vous verrez:

#. Comment exécuter des calculs pré-programmés sur le Arduino en parallèle;
#. Comment utiliser les résultats de ces calculs pour ajuster les sorties du
   Arduino;
#. Comment transmettre les résultats de ces calculs via la ligne série;
#. Comment effectuer d'autres calculs avec Python;
#. Comment sauvegarder le résultat de ces calculs.
