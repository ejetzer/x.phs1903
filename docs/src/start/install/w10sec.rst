Téléchargements reconnus sur Microsoft Edge
----------------------------------------------

Si vous utilisez Microsoft Edge, il est possible que vous receviez un avertissement lors du téléchargement de
fichiers exécutables comme l'installateur de Spyder. Il s'agit d'une `interruption de sécurité d'un téléchargement`_,
mais dans le cas précis des logiciels requis pour le cours, vous pouvez accepter le téléchargement sans risque. Si vous vous sentez motivés, vous pouvez aussi déclarer le fichier comme étant fiable.

.. _`interruption de sécurité d'un téléchargement`: https://learn.microsoft.com/en-us/deployedge/microsoft-edge-security-downloads-interruptions
