Paramètres de sécurité de Windows 11
--------------------------------------

Sur Windows 11, les paramètres de sécurité par défaut empêchent l'exécution d'applications inconnues. Pour pouvoir
installer Spyder, il faut donc ouvrir l'application de `Sécurité Windows`_ et désactiver `Smart App Control`_ et la
vérification des exécutables. Faites attention aux fichiers que vous téléchargez et ça ne devrait pas poser problème.

.. _`Sécurité Windows`: https://support.microsoft.com/en-us/windows/security/windows-security/stay-protected-with-the-windows-security-app

.. _`Smart App Control`: https://support.microsoft.com/fr-fr/windows/security/threat-malware-protection/smart-app-control-frequently-asked-questions
