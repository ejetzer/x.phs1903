Compatibilité avec les cartes Arduino Nano Every
-----------------------------------------------------

La première fois que vous insèrerez la carte Arduino Nano Every, l'environnement Arduino ne sera pas configuré pour
compiler du code adapté à la carte. Dans le gestionnaire de cartes, cherchez ``megaavr`` et installez le module
``Arduino megaAVR Boards``. Acceptez l'installation de chaque élément. Sur Windows, l'autorisation sera demandée pour
chaque pilote installé. Sur MacOS, il est possible qu'il soit nécessaire d'installer les outils de ligne de
commande pour la commande ``xcrun``.
