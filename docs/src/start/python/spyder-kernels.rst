Installation du module ``spyder-kernels``
-------------------------------------------

Le module :mod:`spyder-kernels` permet à Spyder d'interagir avec un interpréteur Python.
Il doit être installé pour qu'un interpréteur puisse être utilisé dans Spyder.

Installation sur MacOS
........................

#. Ouvrir l'application :file:`/Applications/Utilitaires/Terminal.app`.
#. Entrez la commande

   .. code:: shell

      python3.14 -m pip install spyder-kernels

   L'installation devrait se dérouler sans problème.


Installation sur Windows
..........................

#. Ouvrir l'application :file:`cmd.exe` ou PowerShell.
#. Entrez la commande

   .. code:: shell

      py -3.14 -m pip install spyder-kernels

   L'installation devrait se dérouler sans problème.
