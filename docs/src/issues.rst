[BOGUE] L'avertissement d'avrdude lors de la compilation pour Arduino Nano Every n'est pas documenté
......................................................................................................

Voir en ligne: https://github.com/ejetzer/x.phs1903/issues/14.

**Décrivez le bogue** ``avrdude`` affiche l'avertissement suivant quand
on compile et téléverse un programme pour Arduino Nano Every:

.. code:: txt

   avrdude: jtagmkII_initialiaze(): Cannot locate "flash" and "boot" memories in description

**Pour reproduire le bogue** Les étapes pour reproduire le problème:

1. Ouvrir un des exemples Arduino de xphs1903
2. Compiler et téléverser vers une carte Arduino Nano Every

**Comportement attendu** Incertain: les utilisateurs sont néophytes.
