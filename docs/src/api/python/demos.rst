Démonstrations
-------------------------

Les modules de démonstration sont destinés à être appelés en ligne de commande:

.. code:: shell

   $ python3.14 -m xphs1903.demos.<demo précise> [--debug]

Les démonstrations accessibles sont:

* :mod:`xphs1903.demos.dummy.signal`
* :mod:`xphs1903.demos.serial.text.echo`
* :mod:`xphs1903.demos.serial.text.arduino`
* :mod:`xphs1903.demos.serial.data.echo`
* :mod:`xphs1903.demos.serial.data.arduino`
* :mod:`xphs1903.demos.acq.echo`
* :mod:`xphs1903.demos.acq.arduino`
* :mod:`xphs1903.demos.calcul.echo`
* :mod:`xphs1903.demos.calcul.arduino`
* :mod:`xphs1903.demos.plot.static.image`
* :mod:`xphs1903.demos.plot.static.pyplot`
* :mod:`xphs1903.demos.plot.static.tk`
* :mod:`xphs1903.demos.plot.dynamic.image`
* :mod:`xphs1903.demos.plot.dynamic.pyplot`
* :mod:`xphs1903.demos.plot.dynamic.tk`
* :mod:`xphs1903.demos.plot.interactive.pyplot`
* :mod:`xphs1903.demos.plot.interactive.tk`
* :mod:`xphs1903.demos.gui.app`
* :mod:`xphs1903.demos.gui.selecteur`
* :mod:`xphs1903.demos.gui.moniteur`
* :mod:`xphs1903.demos.gui.tableau`
